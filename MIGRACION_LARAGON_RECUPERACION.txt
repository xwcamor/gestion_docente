INSTALACIÓN LIMPIA — SQL ÚNICO (ACTUALIZADO)

El proyecto se reinstala desde cero cuando sea necesario. El procedimiento
recomendado usa un solo archivo:

  database/gestion_docente.sql

ADVERTENCIA: el SQL contiene DROP DATABASE IF EXISTS gestion_docente y elimina
la base anterior completa. Ejecutarlo solo cuando se quiera reiniciar todo.

CORRECCIÓN DEL ERROR MYSQL 1059
- El índice de generated_documents usa gd_mod_type_ver_idx.
- El índice de curriculum_content_items usa cci_week_category_approved_idx.
- Ambos nombres son explícitos y cortos; se evita que Laravel genere nombres
  automáticos que superan el límite de 64 caracteres de MySQL.
- Si una migración previa falló y dejó tablas parciales, elimina la base
  gestion_docente antes de repetir la instalación limpia.

SQL ÚNICO Y REGISTRO DE MIGRACIONES
El SQL crea todas las tablas (incluyendo cache, cache_locks, sessions, jobs,
job_batches y failed_jobs) e inserta en la tabla migrations los 18 nombres de
migración que corresponden al esquema.

Para la instalación limpia usa únicamente:
  php artisan db:seed

No ejecutes php artisan migrate ni php artisan migrate:fresh en este flujo:
el SQL ya creó todas las tablas y marcó las migraciones como aplicadas.

SECUENCIA COMPLETA
1. Habilitar ZIP en Laragon: Menu / PHP / Extensions / zip; reiniciar Laragon.
2. Ejecutar composer install.
3. Copiar .env.example a .env y configurar DB_HOST, DB_PORT, DB_DATABASE,
   DB_USERNAME y DB_PASSWORD. Mantener CACHE_STORE=file, SESSION_DRIVER=file,
   QUEUE_CONNECTION=sync en el entorno local.
4. Importar database/gestion_docente.sql en phpMyAdmin/HeidiSQL.
5. Ejecutar:

   php artisan key:generate
   php artisan db:seed
   php artisan gestion:crear-profesor --admin
   php artisan serve

6. Abrir http://127.0.0.1:8000/login.

Las migraciones permanecen en el repositorio como historial de desarrollo.
Para la instalación limpia del usuario, el SQL único crea la estructura y
registra las migraciones como ejecutadas; db:seed carga únicamente los datos
iniciales. Composer install es otro paso: instala las dependencias PHP y no
crea ni modifica el esquema de MySQL.
